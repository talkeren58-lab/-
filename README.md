# BOQ Tool — כלי כתב כמויות מתוכניות מכרז

כלי עבודה חוזר לקבלן ביצוע עצמאי, ליצירת כתבי כמויות (BOQ) מתוכניות
אדריכליות של מכרזי קבלנים באמצעות Claude Code.

תהליך העבודה המלא, מבנה קובץ הידע (`knowledge_base.xlsx`), ומבנה קובץ
הפלט מתועדים ב-[`CLAUDE.md`](./CLAUDE.md) — הוא נטען אוטומטית בתחילת כל
הרצת Claude Code בתיקייה הזו.

## שימוש מהיר

**הרצה ראשונה** (בניית קובץ הידע): הכניסו כתב כמויות לדוגמה לתיקיית
[`דוגמאות/`](./דוגמאות), פתחו הרצת Claude Code, ובקשו לבנות את
`knowledge_base.xlsx` מהדוגמה.

**כל פרויקט חדש לאחר מכן**: פתחו הרצת Claude Code באותה תיקייה וצרפו רק
את קובץ ה-PDF של תוכניות המכרז.
