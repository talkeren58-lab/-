# דוגמאות

תיקייה זו משמשת רק בהרצה הראשונה, לצורך בניית `knowledge_base.xlsx`.

הכניסו לכאן:

- כתב כמויות קיים ומוכן (xlsx) שהקבלן נוהג להשתמש בניסוח שלו.
- קובץ/י PDF של תוכניות תואמות, אם יש, כדי לקשר בין הפריטים בכתב
  הכמויות לאופן שבו הם מופיעים בתוכנית.

לאחר שנבנה `knowledge_base.xlsx` בשורש הפרויקט ואושר, אין יותר צורך
בתיקייה הזו לצורך פרויקטים חדשים — הקלט היחיד לכל פרויקט הבא הוא קובץ
ה-PDF של תוכניות המכרז שלו.
